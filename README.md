# GauntletModelManipulations

Explanatory information for this modeling tool can be found in the separate repo TheGauntletModel https://github.com/lizallyn/TheGauntletModel

This repo contains all data inputs, scripts, and output files associated with the paper in prep for Ecological Modelling titled "Agent-based modeling framework for exploring the impact of predator management scenarios on predator learning and foraging behavior", which is building off of Chapter 2 of my thesis, available here: https://www.researchgate.net/publication/394287123_Participatory_Modeling_to_Evaluate_Tribal_Pinniped_Harvest_in_Puget_Sound_as_a_Tool_for_Salmon_Recovery
